# Expense Tracker 💸

Expense Tracker is a simple and interactive web application built using HTML, CSS, and JavaScript. It helps users manage their personal finances by allowing them to set budgets, track expenses, and maintain a clear overview of their spending habits in real-time.

## 🌟 Features

- **Set and Update Budget**: Users can define their budget and update it anytime.
- **Add Expenses**: Record expenses with custom titles and amounts.
- **Real-Time Calculations**: Automatically calculates and displays total budget, total expenses, and remaining balance.
- **Expense List**: View all expense entries in a dynamic list format.
- **Edit/Delete Entries**: Modify or remove individual expense items instantly.
- **Responsive UI**: Clean and responsive design for a smooth user experience across devices.

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
